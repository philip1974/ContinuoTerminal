# examples

Runnable examples of the packages in this repo:

- [`standalone-cli`](./standalone-cli/) — Node CLI demoing `server-node` over stdio.
- [`minimal-react-host`](./minimal-react-host/) — Vite + React 19 host for `react-terminal` against a mock MCP adapter.
- [`minimal-agent-host`](./minimal-agent-host/) — stdio launcher pattern with a primary controller and a secondary terminal session.
- [`standalone-cli-host`](./standalone-cli-host/) — `@continuo-terminal/host` over local HTTP with a scoped bearer token.
- [`tauri-sidecar`](./tauri-sidecar/) — Rust / Tauri 2 sidecar demo (source demo, not a production packaging recipe).
